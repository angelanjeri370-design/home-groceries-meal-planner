Home Groceries Management and Meal Planner System

About the Project

The Home Groceries Management and Meal Planner System is a web-based application designed to help households manage grocery stock, monitor consumption, and organize weekly or monthly meal plans.

The system aims to make household grocery management easier by helping users keep track of available items, identify low-stock groceries, and plan meals more efficiently.

Features

- User Authentication: Secure registration and login functionality.
- Grocery Management: Record and manage household grocery items.
- Consumption Tracking: Track grocery usage and estimate how long items may last.
- Low-Stock Notifications: Help users identify groceries that need replenishing.
- Meal Planning: Create and manage weekly or monthly meal plans.
- Reminders: Support timely grocery and meal-planning routines.
- Meal Suggestions: Provide suggestions based on previously recorded meal plans.

Technologies Used

- Frontend: HTML, CSS, JavaScript
- Backend: PHP
- Database: MySQL
- Development Environment: Visual Studio Code, XAMPP

Database

The project includes SQL files for defining database tables and setting up the database structure.

Installation and Setup

1. Install "XAMPP" (https://www.apachefriends.org/).
2. Clone or download this repository into the XAMPP "htdocs" directory.
3. Create the required MySQL database using phpMyAdmin.
4. Import the relevant SQL files to create the required tables.
5. Configure the local database connection in "config.php".
6. Start Apache and MySQL from the XAMPP Control Panel.
7. Open the application through your browser using the appropriate local project URL.

Note: Database names, table requirements, and configuration details may vary depending on the current project version.
